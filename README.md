## What are websockets? (by Donald G)
Websockets are a certain type of communication protocol that enables two-way interactinos between a client (ex. a browser) and a server. They allow parties to send data to each other at anytime, kind of like a phone call since both ends interact with each other. Now while the websockets aren't too hard if you know what you're doing, the process can be made much easier with the library known as Socket.IO. What makes WebSockets more complex without Socket.IO is that you'd have to manually implement features such as reconnection logic and fallback mechanisms, and you'd have handle complex scalability for large user bases on top of that. Socket.IO makes reconnection logic easier by having built-in mechanisms that handle all the things you'd have to do manually. It also makes the complex scalability for large user bases easier by having built in features such as multiplexing, namespaces, scalability with adapters such as Redis, and automatic reconnection and fallbacks.
